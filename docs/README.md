# Vault · 端侧优先的个人知识库

> 项目代号 **Vault**（产品名待定）· 三端：Android / iOS / Windows · 无自建后端 · WebDAV 同步 · 端侧 AI

**一句话定位**：把「笔记 / 想法 / 日记 / 网页归档 / 密码」统一进一个端到端加密的本地库，用自己的 WebDAV 同步，用端侧 AI 让三个月前看过的东西随时能被找回来 —— 数据永远在用户手里。

## 核心决策摘要

| # | 决策点 | 选择 | 代价 |
|---|---|---|---|
| D1 | 服务端 | 无后端，直连用户 WebDAV | 无推送、无服务端抓取、无协作 |
| D2 | 平台 | Android / iOS / Windows | 放弃 Web |
| D3 | 数据模型 | 统一 `entry` + `kind` 区分 | 视图层做差异化 |
| D4 | 同步粒度 | 一条 item 一个加密文件 | 文件数多，PROPFIND 成本上升 |
| D5 | 冲突策略 | 永不覆盖，冲突必留副本 | 需要冲突副本 UI |
| D6 | 变更检测 | 设备水位探测（1 请求） | 依赖每设备写状态文件 |
| D7 | 密码与 AI | 密码/日记走端侧模型（L0） | 端侧质量低于云端 |
| D8 | 向量同步 | 加密后随条目同步 | 需本地解密镜像表 + 模型一致 |
| D9 | 网页归档 | 正文层自动 + 快照层按策略 | 需配额与清理策略 |
| D10 | 模型分发 | 内置小模型 + 一键下载 | 需处理国内源与备份排除 |
| D11 | **首页定位** | **对话式（「聊天」），不是分类目录** | 需要会话抽屉做导航 |
| D12 | **视觉风格** | **手绘草图风（便签/硬阴影/虚线）** | 与"银行级安全"的企业感有张力 |
| D13 | **字体策略** | **三角色（正文/标题/等宽）+ 内置 3 套 + 用户导入** | 包体 +13.9 MB；字体不跨设备同步 |
| D14 | **本地库加密** | **SQLCipher 整库加密（`source: sqlcipher` 一行配置）** | 包体 +2~4 MB/ABI；需断言 `cipher_version` 防静默降级 |
| D15 | **密钥结构** | **主密码 → KEK → 包裹 DEK → HKDF 派生 6 条子密钥** | Argon2id 纯 Dart 实测 2.1s，解锁页必须有进度 |
| D16 | **恢复码** | **24 词 BIP-39（带校验和）+ HKDF，不跑 Argon2** | 抄错一个词当场可发现；恢复码 = 库的备份钥匙，必须警告不要截图 |
| D17 | **写入路径** | **`WriteGateway` 是唯一写入口，实体变更与 oplog 同事务** | 绕过它就等于静默丢同步；已在测试里用"故意失败"验证回滚 |
| D18 | **条目加密信封** | **明文头 {entity,id,rev} + AAD = 头部字节** | 解决"AAD 需要 rev 但 rev 在密文里"的鸡生蛋；oplog 与云端 item 字节一致，可直接 PUT |
| D19 | **活动埋点** | **按 (kind, entry) 时间窗口合并，不记流水账** | 浏览 30 分钟 / 编辑 5 分钟 / 搜索 60 秒；`dwellMs` 是最有价值的字段 |
| D20 | **路由判断** | **全 App 只有 `resolveGateScreen` 一处决定显示哪一屏** | 「未确认的恢复码」优先于状态机，否则 24 个词永远看不到 |
| D21 | **解锁进度** | **不伪造百分比，只显示真实秒数 + 不确定转圈** | Argon2id 没有进度回调；假进度条会在 1% 卡两秒，比没有更焦虑 |
| D22 | **meta.enc 写入** | **先写 .tmp 再 rename** | 它是解锁唯一入口，写一半断电等于永久锁死整个库 |

## 关键预算

| 指标 | 目标 |
|---|---|
| 冷启动到可交互 | < 1.2 s |
| 常规同步（无变化） | ≤ 3 个 HTTP 请求 |
| 常规同步（有变化） | ≤ 200 个请求 / 次 |
| 5000 条向量重建 | < 8 min（中端机） |
| 安装包体积 | < 60 MB |
| 峰值内存 | < 400 MB |
| 单条目体积 | 正文 ≤ 1 MB / blob ≤ 20 MB |
| **同步丢失容忍度** | **0** |

## 四条工程红线

1. **禁止无条件 PUT。** 所有写操作必须带 `If-Match` 或 `If-None-Match`。
2. **禁止全量同步 `blobs/`。** 快照按需下载。
3. **禁止混合不同 embedding 模型的向量。** 每条向量必须带 `model_id + dim`。
4. **禁止绕过 `VaultDatabaseOpener` 打开数据库，禁止只查 `cipher_version` 就认为已加密。**
   本项目全局用 SQLCipher，所以「忘了 `PRAGMA key`」的连接照样报出版本号，
   然后以明文建库。必须同时断言 `PRAGMA cipher_salt` 非空。
5. **禁止把密钥材料写进日志、异常信息或 `toString`。**
   `SecretBytes` 的指纹是 `sha256(key)` 的前 4 字节，不是密钥本身的字节。
   任何需要"认出这是哪把 key"的地方都用指纹，不要打印 `toHex()`。
