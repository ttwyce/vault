# 10 · UI 设计方案（手绘草图风 · 现行）

> 本文档为**唯一现行的视觉规范**。
> 早前两版方案（暖色编辑风、冷灰蓝简洁风）已归档至 `_archive/design-v1/`，不再维护。

---

## 1. 风格定位

**「手绘草图」**：每个角圆度都不同、虚线描边、硬偏移阴影，配马克笔红与圆珠笔蓝。像写在便签上的界面，亲切但精度低。

**为什么是这个风格**

| 理由 | 说明 |
|---|---|
| 与产品气质匹配 | 这是「自己的档案馆」，不是企业工具。手写感 = 私人、非正式、可涂改 |
| 降低"AI 味" | 满屏 Inter + 渐变 + 玻璃是 2024–26 年 AI 产品的通用长相，手绘风天然避开 |
| 容纳不确定性 | 产品里有大量"AI 建议""待你决定""草稿态"，手绘的潦草感正好承载这些中间状态 |
| 三端一致成本低 | 纯 CSS/Dart 绘制，不依赖复杂素材，移动端与桌面端可完全一致 |

**风格参数来源**：`sketch-hand-drawn-mobile`（风格图鉴 84 号）

## 2. 五条硬规则

这五条缺任何一条，风格就塌成"廉价手绘"。

### ① 每个角圆度都不同

```css
border-radius: 18px 26px 16px 28px / 26px 16px 30px 18px;
```

斜杠前是水平半径、后是垂直半径，**八个值全不一样**。全站准备四套轮换：

```css
.wob-a { border-radius: 18px 26px 16px 28px / 26px 16px 30px 18px; }
.wob-b { border-radius: 26px 16px 28px 18px / 16px 28px 18px 26px; }
.wob-c { border-radius: 14px 20px 16px 22px / 20px 14px 24px 16px; }
.wob-d { border-radius: 22px 14px 20px 16px / 14px 22px 16px 20px; }
```

### ② 虚线描边

`border: 2px dashed`。实线立刻变"设计稿"，虚线才是"草稿"。
细部用 `1.5px dashed`，强调用 `2px`。

### ③ 零模糊硬阴影

```css
box-shadow: 4px 4px 0 #2D2D2D;   /* 没有 blur，没有透明度 */
```

三档：`4px`（卡片）/ `3px`（按钮、导航条）/ `2px`（小标签、选中项）。
**暗色模式下阴影颜色换成半透明白**，否则在深底上看不见。

### ④ 整体歪一点

`transform: rotate(-.7deg)` 或 `.5deg`，相邻元素交替方向。
**这一条最容易漏，但没有它，前三条加起来还是像模板。**

规则：
- 卡片：±0.3~0.5deg
- 按钮：不倾斜（可点击元素保持稳定）
- 选中项：比其他元素多歪 0.4deg（`-0.8deg` vs `-0.4deg`）
- **正文永远不倾斜**，只倾斜容器

### ⑤ 纸纹

```css
body::before {
  background-image: url("data:image/svg+xml,...feTurbulence...");
  opacity: .35;
  mix-blend-mode: multiply;
}
```

极淡的噪点，让底色不像纯色块。**只铺一次在 body 上，不要每张卡片都加**（性能）。

### 颜色分工（不可混用）

| 颜色 | 只用于 |
|---|---|
| **红** | AI 动作、当前状态、主按钮、正在进行的步骤 |
| **蓝** | 旁注、链接、"了解更多"、需要你决定的事 |
| **绿** | 已完成的勾选、检查通过 |

| **墨** | 其余一切 |

## 4. 字体

> **完整实现见 [15 字体系统](15-字体系统.md)**。本节只保留设计侧结论。

字体分三个角色，不是一个全局字体 —— 手绘风的核心是**两套声音**：
书写体讲内容，等宽体报数据。

| 角色 | 字体 | 用途 |
|---|---|---|
| 界面与正文 | **霞鹜文楷 Lite**（内置，13.3 MB） | 列表、按钮、笔记正文、阅读 |
| 标题与展示 | **Caveat**（内置，394 KB，仅拉丁） | 页面标题、字标、卡片大标题 |
| 数字与等宽 | **JetBrains Mono**（内置，264 KB） | 时间、字数、标签、TOTP、代码 |

三者均为 SIL OFL 1.1，随包分发。中文只内置一套 —— 任何覆盖 GB2312 的中文字体都在
10 MB 量级，多放一套包体就不可接受，其余走系统字体或用户导入。

**回退链是硬要求**：不存在一个字体同时覆盖中文、西文与全部符号，每个字体都必须带
非空 fallback（`FontCatalog.cjkFallback`），少一项就会在某个页面看到方框。

### 用户可换字体

四套预设（手写默认 / 阅读优先 / 系统原生 / 极客等宽）+ 按角色单独指定 +
导入本地 TTF/OTF/TTC。字体**不参与同步**，是纯本机偏好。

### 字号阶梯

| Token | 字号 / 行高 | 字体角色 | 用途 |
|---|---|---|---|
| 大标题 | 21 / 1.3 | display | 页面标题（聊天、归档、账号） |
| 卡片标题 | 13~14 / 1.4 | display | 条目标题 |
| 正文 | 13.5 / 1.7 | ui | 常规正文 |
| 阅读正文 | 14.5 / 1.9 | ui | 归档阅读器 |
| 小字 | 11.5 / 1.6 | ui | 摘要、说明 |
| 微字 | 10.5 / 1.5 | **mono** | 时间、元数据 |
| 标签 | 10.5 | **mono** | 药丸、徽章 |

**最小字号 10.5px**。手写体在 10px 以下会糊成一片。

字号不随字体变化 —— 不同字体的 x-height 差异靠行高吸收。改字号会让跨端对不齐。

## 5. 间距

4px 基准，但比常规 UI **更松**（手写体视觉重量轻，需要更多留白）：

| Token | 值 | 用途 |
|---|---|---|
| xs | 4 | 图标与文字 |
| sm | 7 | 紧凑元素 |
| md | 10~12 | 卡片内边距 |
| lg | 14~16 | 区块间距 |
| xl | 18~22 | 面板内边距 |
| xxl | 26~34 | 页面级留白 |

## 6. 图标：全部自制

**不用任何图标库**。图标库的直线和完美圆角会瞬间暴露"这是模板"。

### 五枚导航图标

| 名称 | 画法 | 关键细节 |
|---|---|---|
| 聊天 | 歪的气泡 + 四角星 | 尾巴收口不对齐（`5.3 19.4 → 5.2 16.2`） |
| 记录 | 两张错位的纸 + 三条横线 | 后面那张只露一条顶边 |
| 日记 | 书 + 书脊 + 飘出的书签 | 书签是折角的两段线 |
| 归档 | 箱盖一条弧 + 箱身 + 提手 | 箱盖中间微微塌下去，不是直线 |
| 密码 | 钥匙头 + 钥匙孔 + 带齿的柄 | 两个椭圆**不同心** |

### 绘制原则

1. **没有一条绝对水平/垂直的直线** —— 全部用 `C`（三次贝塞尔），控制点不对称
2. **左右不完全对称** —— 例：归档箱身左 `5.5` 右 `18.4`，右侧高 0.2px
3. `stroke-width: 1.75~1.9`，`stroke-linecap: round`，`fill: none`
4. viewBox 统一 `0 0 24 24`
5. 选中态图标 `stroke: var(--red)`

### 其他图标

三横杠（三条长度不一的曲线）、加号（两笔不等长）、搜索（歪圆 + 短柄）、勾（两笔折线）—— 同规则自制。

## 7. 组件规范

### 7.1 按钮

```css
.btn {
  height: 31px; padding: 0 13px;
  border: 2px solid var(--line);
  border-radius: 14px 20px 16px 22px / 20px 14px 24px 16px;
  box-shadow: 3px 3px 0 var(--line);
  background: var(--surface);
}
.btn:hover { transform: translate(1px,1px); box-shadow: 1px 1px 0 var(--line); }
```

| 变体 | 样式 |
|---|---|
| `pri` | 红底白字，阴影同色 |
| `blue` | 蓝底白字 |
| `ghost` | 虚线边框、无阴影 |
| `sm` | 高 25px，字号 11px |

**悬停不用缩放**（会抖动），用"位移 1px + 阴影变浅"模拟按下。

### 7.2 卡片

```css
.card {
  background: var(--surface);
  border: 2px dashed var(--line);
  border-radius: 18px 26px 16px 28px / 26px 16px 30px 18px;
  box-shadow: 2px 2px 0 var(--line);
}
```

四套 `.wob-a~d` 轮换，**相邻卡片必须用不同套**。

### 7.3 药丸 / 徽章

```css
.pill {
  font-size: 11px; padding: 2px 9px;
  border: 1.5px dashed var(--line-soft);
  border-radius: 12px 16px 12px 18px / 16px 12px 18px 12px;
}
.pill.red  { background: var(--red); color: #fff; border-color: var(--red); }
.pill.blue { background: var(--note2); color: var(--blue); border-color: var(--blue); }
.pill.note { background: var(--note); }
```

### 7.4 输入框

高 30~32px，`1.5px dashed` 边框，聚焦时边框变 `--line`（实线）+ 轻微背景变便签黄。
占位文字用 `--muted` + 常规字重（不倾斜，手写体已足够"软"）。

### 7.5 导航

**桌面侧栏**：悬浮便签条

```css
.rail {
  margin: 10px 8px 10px 10px; padding: 12px 0 10px;
  background: var(--surface);
  border: 2px dashed var(--line);
  border-radius: 19px 15px 21px 15px / 15px 21px 15px 19px;
  box-shadow: 3px 3px 0 var(--line);
  transform: rotate(-.25deg);
}
.ni.on {
  background: var(--note);
  border: 1.5px dashed var(--line-soft);
  box-shadow: 2px 2px 0 ...;
  transform: rotate(-1.2deg);
}
```

**移动底部导航**：同一套规则，五项 `聊天 · 记录 · 日记 · 归档 · 密码`

```css
.mnav {
  margin: 0 12px 12px; padding: 7px;
  border: 2px dashed var(--line);
  border-radius: 17px 21px 15px 23px / 21px 15px 23px 17px;
  box-shadow: 3px 3px 0 var(--line);
  transform: rotate(-.35deg);
}
.mnav span.on { background: var(--note); transform: rotate(-.8deg); }
```

**关键**：选中项要比整条导航**再歪一点**。这种"手贴上去"的错位感是这个风格的灵魂。

### 7.6 抽屉

从左侧滑出，右侧边缘用硬阴影而非模糊：

```css
.drawer {
  background: var(--surface);
  border-right: 2px dashed var(--line);
  border-radius: 0 22px 20px 0 / 0 20px 22px 0;
  box-shadow: 6px 0 0 color-mix(in srgb, var(--line) 22%, transparent);
}
```

遮罩：`rgba(ink, 26%)`，不用模糊。

## 9. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 悬停变色 | 120ms | ease |
| 按钮按下位移 | 120ms | ease |
| 抽屉滑入 | 280ms | `cubic-bezier(.22,1,.36,1)` |
| 页面切换 | 200ms | ease-out |
| 进度条 | 线性 | — |

**禁止**：弹性回弹（bounce）、超过 400ms 的过渡、装饰性循环动画、滚动视差。
手绘风格已经足够"活"，再叠加动效会变吵。

## 10. 无障碍风险与对策

这个风格有四处天然劣势，必须显式处理：

| 风险 | 对策 |
|---|---|
| 手写体小字号可读性差 | 最小字号 10.5px；正文不用手写体替代品，保持 13.5px 以上 |
| 虚线边框在低分辨率下糊 | 桌面 2px / 移动 2px，不小于 1.5px |
| 倾斜影响阅读 | **只倾斜容器，绝不倾斜正文文字** |
| 硬阴影增加视觉噪音 | 只在可点击元素上用；正文卡片用 2px 极浅阴影 |
| 便签黄对比度不足 | 黄底上文字必须用 `--ink`（`#2D2D2D`），不用 `--muted` |
| 颜色表达状态 | 红/蓝/绿必须配图标或文字，不单靠颜色 |

**对比度校验**：`#2D2D2D` on `#FDFBF7` = 13.2:1 ✓；`#6B6459` on `#FDFBF7` = 5.4:1 ✓；
`#FF4D4D` on `#FFFFFF` = 3.2:1（**不达标**，所以红只做背景填充配白字，或做图标不做正文）。

## 11. 落地到 Flutter 的关键点

| CSS 特性 | Flutter 对应 | 注意 |
|---|---|---|
| 非对称圆角 `x/x/x/x / y/y/y/y` | `BorderRadius.only(tl: Radius.elliptical(18,26), ...)` | Flutter 支持椭圆半径，可 1:1 映射 |
| `border: 2px dashed` | **无内置** → `CustomPainter` + `PathMetrics` 沿 RRect 画 dash | 封装 `DashedRRectBorder` |
| `box-shadow: 4px 4px 0` | `BoxShadow(offset: Offset(4,4), blurRadius: 0, spreadRadius: 0)` | 直接支持 |
| `transform: rotate(-.7deg)` | `Transform.rotate(angle: -0.0122)` | 弧度制 |
| 纸纹 | `CustomPaint` + 平铺 PNG + `BlendMode.multiply` | 只铺一次，别放滚动列表里 |
| 手写字体 | `pubspec.yaml` 打包 LXGW WenKai 子集 | 见 §4 |

**建议封装三个组件**，业务层不直接写样式：

```
SketchCard(variant: a|b|c|d)      // 非对称圆角 + 虚线 + 硬阴影
SketchButton(primary|ghost|blue)  // 按下位移
SketchTag(color: red|blue|note)   // 药丸
```

## 12. 验收标准

| # | 标准 |
|---|---|
| U1 | 43 屏中任意相邻两张卡片使用不同的圆角配方（不重复） |
| U2 | 所有可点击元素有 hover / pressed 反馈，且**不产生布局位移**（用 transform 不用 size） |
| U3 | 亮暗双主题下所有正文对比度 ≥ 4.5:1 |
| U4 | 无一屏红色出现超过 3 处 |
| U5 | 正文文字零倾斜 |
| U6 | 图标全部自制，无图标库痕迹（无绝对直线、无完美圆） |
| U7 | 移动端 375px 下无横向滚动，底部导航五项不换行 |
| U8 | 开启系统"减少动效"后所有过渡瞬时完成且功能正常 |
