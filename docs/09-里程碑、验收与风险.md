## 15. 关于「手绘风 vs 安全感」的处理

手绘风适合"私人、可涂改、非正式"的内容（笔记、想法、日记），但**密码库需要另一种气质** —— 用户要看到"这东西很牢"。

建议：密码模块（05/10/16/17 四屏）使用**同色板、同字体、但更克制的变体**：

| 项 | 手绘风 | 密码模块变体 |
|---|---|---|
| 边框 | 2px dashed | 1.5px solid |
| 圆角 | 非对称（8 个值） | 对称 10px |
| 倾斜 | ±0.5deg | 0deg |
| 阴影 | 硬偏移 3px | 无 / 极浅 |
| 红色 | 高频 | 仅用于危险操作 |

其余保持一致（纸白底、墨色、楷体、便签黄选中）。这样既保住整体风格，又不会让用户在存密码时觉得"这是个玩具"。

> 这是一条产品决策，不是纯视觉问题。**先按此实现，若用户反馈"割裂"再统一。**
