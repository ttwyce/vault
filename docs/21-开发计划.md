- 无 Key 配置 UI、无 WebDAV 凭据持久化（合规）、`flutter_secure_storage` 在 `pubspec.yaml:43` 声明但 **lib 零 import**；`path_provider` 已用于 `VaultStorage` / `FontStore` / `DatabaseOpener` / `SettingsStore`，可直接复用取目录，无需新依赖。

**总判定**：本轮允许的工作只有 §5 A 的「装配接线 + 跨链路集成 + 既有代码收敛」四类，且每一步必须能写明「接线了什么、为什么不是重复」（§4 L108）。§5 B 全部列为等待项，不用纯逻辑假装完成。

- 若后续判断「连读安全存储都需要真实 Key 才算外部条件」，则 P2 整体降级为等待项，本计划只保留 P0/P1/P3/P4/P5，不影响其余步骤。

按「占 §5 A 清单 / 解锁真实功能 / 不碰硬门槛 / 改动面小」排序：**P0 → P1 → P3 → P4 → P5 → P2（最后做，或按上述裁定降级）**。

2. `ExportBackupPage.plaintextExportRunner`：

## 6. P3 · 跨链路集成测试（§5 A2，本计划的核心交付）

**一条测试文件** `test/cross_link_pipeline_test.dart`，用 `TestApp.create()` 建 A/B 两个内存库 + 同一把 `VaultKeys`，一台 `HttpServer.bind(127.0.0.1, 0)` 同时扮演可变 HTML 源站、`/vault/blobs/xx/<hash>.bin` 与 `/backup/`，一个 `Directory.systemTemp.createTemp()` 做 Markdown 中转。

顺序（每一步都断言真实落库，不是断言返回值）：

1. **L1 抓取**：`HttpArchiveFetcher(baseUrl: server).fetch()` → `WriteGateway.writeEntry(EntryWrite.create(kind: bookmark, body, meta: ArchiveMeta...))`，断言 `entry` 与 `oplog` 同行、FTS 可查。
2. **L2 PDF**：`PdfSnapshotService.generate()` 真实生成并 `recordArchiveBlob(kind=2, local=1)`、`status=full`；因 `PdfSnapshotResult` 不带字节，测试内用 `buildSimplePdf(body).bytes` 重算（胶水写在测试里，不新增产品模块）。
3. **blob 上传**：当前**无上传器**，测试内直接 `backend.put(CloudLayout.blobPath(hash), bytes, condition: createOnly())` 作为临时胶水，并在测试注释与 §0 记录中把它明确列为「产品缺口：blob 上传器未实现」。不新增 `http_blob_uploader.dart`（§3/§4 禁止再包一层）。
4. **另一设备按需下载**：因 `blob_ref` 不走 oplog（§ `write_gateway.dart:1644`），用 P1 的 `MarkdownExporter → MarkdownImporter` 把条目迁到 B 库，再在 B 库 `recordArchiveBlob(local: false)`（或等价网关调用）后跑 `HttpBlobDownloader.download`，断言 `local=1`、字节数与 sha256 一致；同时断言「下载器不落盘」这一现存限制，不修改它。
5. **内容变更重抓**：改 HTML 响应 → A 库 `ContentChangeService.checkAndApply()` → 断言 `entry_history` 保留旧版、`simhash` 更新、`link_check` 有新行（复用 `content_change_service_test.dart` 桩）。
6. **加密备份 / 还原**：`EncryptedBackupService(db, backend: HttpClientWebDavBackend(本地 server), keys)` `upload()` → `restore()` 校验 `VLT1` manifest、错密钥失败、篡改失败；断言「restore 目前只返回 manifest、不写回条目」并明确记为产品缺口，不替它补写库逻辑。

**为什么不是重复工作**：它把 §3 表里 6 条以上已落地真实链路串成一条可回归路径，属于 §0 (B)；只新增测试与测试内胶水，不新增判定层/meta/客户端/徽章，不刷任何文档数字。

**验收**：`flutter analyze` + `flutter test --reporter compact --concurrency=1` 全绿；`git diff --check`；提交信息写明「属于 §5 A2 跨链路集成」。
