### 1.1 只读仓库

```dart
import 'package:vault/data/entry/entry_repository.dart';

final repo = ref.watch(entryRepositoryProvider);

Future<List<EntrySummary>> repo.list({EntryKind? kind, bool includeDeleted = false, int limit = 200});
```


纯函数（`entry_models.dart` 导出，可直接单测）：


### 1.2 写入口

```dart
import 'package:vault/data/write/write_gateway.dart';

final gateway = ref.watch(writeGatewayProvider);

await gateway.writeEntry(EntryWrite.create({String? id, EntryKind kind, String? title, String? body, String? meta}));
await gateway.writeEntry(EntryWrite.update({required String id, String? title, String? body, String? meta}));
await gateway.writeEntry(EntryWrite.delete({required String id}));
await gateway.writeEntry(EntryWrite.restore({required String id}));
// 返回 EntryWriteResult { EntrySnapshot snapshot; int oplogSeq; bool changed; }
```

**关键语义**：`update` 是整体替换，`title/body/meta` 传 null 表示**清空**该字段，不是"保持不变"。要部分更新就先 `repo.getRow` 读旧的再改。
`EntryKind` 枚举：`note(1) / thought(2) / diary(3) / aiDiary(4) / bookmark(5) / credential(6)`。
创建失败会抛 `WriteException`（code: `not_found` / `already_deleted` / `exists` / `invalid`）。

## 4. 行为规格

### A · 记录页（重写 `records_page.dart`）

- 顶部：标题「记录」+ 右侧「新建」按钮（`SketchIconButton(glyph: SketchGlyph.plus)`）。
- 第二行：搜索框（只读样式即可，输入时调 `repo.search` 实时过滤；空输入显示普通列表）。
- 第三行：两个分段「笔记」「想法」（用 `SketchButton`/`SketchTag` 表达选中态），再加标签 chips（横向滚动，取 `repo.tags()`，点选过滤）。
- 列表：`repo.list(kind: 当前分段)` 渲染 `EntrySummary`，每行：标题 + 片段两行 + 右下等宽时间（`yyyy-MM-dd HH:mm` 本地时区）+ 标签小字。空状态给一句「还没有内容，点右上角新建」。
- 点条目 → `EditorPage(entryId: id)`。
- 卡片视觉与 `fonts_page.dart` 的列表一致。

### B · 日记页（重写 `diary_page.dart`）

- 顶部标题「日记」+ 右上「补写」按钮 → `EditorPage(initialKind: EntryKind.diary)`。
- 月份导航：`‹ 2026年11月 ›`，左右切换月份，只允许往回/往前不限。
- 月历：周日起始（周日一二三四五六），每格显示日期；三态：**当天有用户日记**=实心点、**只有 AI 日记**=空心点、**今天**=红底白字。AI 日记判定：`EntrySummary.kind == EntryKind.aiDiary`。
- 月历下方：所选日期的条目列表（`diaryForMonth` 的结果，按 `updatedAt` 倒序，AI 日记用 `SketchTag` 标「AI」）。没选日期时显示当月全部、按日期分组。
- 点条目 → `EditorPage(entryId: id)`。

### C · 编辑器（新建 `editor_page.dart`）

- 进入时若 `entryId != null` 先 `repo.getRow` 加载，`isBusy` 期间显示转圈。
- 顶部返回键（`SketchIconButton(glyph: SketchGlyph.close)`）+ 标题 + 右上「保存」。
- 正文区：一个大 `TextField`（无边框、`maxLines: null`），标题用单独的无边框大号 `TextField`。kind 用 `SketchTag` 显示（如「笔记」「日记」），不可改（本轮）。
- 保存：新建走 `EntryWrite.create`，编辑走 `EntryWrite.update`（**整体替换语义**，读到的旧值没改的字段也要原样传回）。保存成功后 `Navigator.pop`。
- 保存失败（`WriteException`）在页面内显示 `context.sketch.red` 提示条，不 pop。
- 标题为空时自动用正文首行兜底（`displayTitle`），空正文则保存「无标题」。

### D · 组织页（新建 `organize_page.dart`）

- 标题「分类与标签」，两块内容：
  1. **分类**：`buildCategoryTree(await repo.categories())` 渲染两级树，每行显示名称 + `entryCount`。空状态「还没有分类」。
  2. **标签**：`repo.tags()` 渲染标签云（`SketchTag`，按 count 大小不重要，颜色随机走 `SketchTone` 两三种交替），显示 `name (count)`。
- 本轮**没有任何写操作按钮**——加/删/改是下一轮。页面上写明「管理功能将在后续版本开放」。

## 6. 已知陷阱（前人踩过，别重蹈）

- `SketchCard` **没有 `borderColor` 参数**，要红框用 `SketchFrame(borderColor: p.red)`。
- drift 查询构造器类型推断用 `where((t) => ...)`，别写 `where((Entry t) => ...)`（`Entry` 不是表类名）。
- `EntryKind` 在 `package:vault/data/db/tables/entry_tables.dart`。
- 组件树里别用 `const` 修饰依赖 `context` 的 widget；不依赖的尽量 `const`（analyzer 会提示）。
- 时间格式化用 `intl` 的 `DateFormat`（项目已依赖 `intl`），别手写补零。
